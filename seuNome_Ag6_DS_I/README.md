## 📋 Sobre o Projeto

Este programa foi desenvolvido para simular um **sistema de desconto progressivo** para uma loja online. Ele calcula automaticamente o desconto que o cliente recebe com base no valor total da compra, aplicando as seguintes regras:

- Compras abaixo de **R$ 200,00** → **5%** de desconto
- Compras entre **R$ 200,00** e **R$ 299,99** → **10%** de desconto
- Compras acima de **R$ 300,00** → **15%** de desconto

O programa foi desenvolvido em Python e utiliza estruturas condicionais (`if`, `elif`, `else`) para aplicar as regras corretamente.

---

## 🎯 Objetivo

O objetivo principal é praticar:

- Uso de **estruturas condicionais** (`if`/`elif`/`else`)
- **Entrada e saída** de dados com `input()` e `print()`
- **Conversão de tipos** com `float()`
- **Formatação de números** para exibir valores monetários
- Organização e comentários no código
