# :zap: Segundo Projeto - Calculadora de Consumo e Custo Elétrico :moneybag:
O objetivo deste projeto é estimar quanto um aparelho gasta de dinheiro e energia elétrica por mês. O programa solicita o **nome do aperelho**, **sua potencia** e **quantas horas ele fica ligado por dia**. **Calcula o consumo mensal** usando a formula **consumomensal= (potencia * tpm * 30) /1000** e logo depois mostra os **dados de saida**.

---
# :clipboard: Instruções para executar o programa,exemplo: 
Digite o nome do aparelho: Ventilador
Digite a potência do aparelho (Watts): 100
Digite o tempo médio de uso diário em horas: 8

O consumo mensal do aparelho Ventilador é de 24.0 kWh.
O aparelho Ventilador custa aproximadamente R$ 18.00 por mês em energia.
